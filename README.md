# BukoPie's Agents — Releases

This public repository is used only to distribute compiled releases and update metadata for BukoPie's Agents.

The application source code and development workflow remain in the private [AgentAPI repository](https://github.com/xBukoPie/AgentAPI).

## Downloads

Published versions appear under [Releases](https://github.com/xBukoPie/AgentAPI-Router/releases).

For Windows, each release is expected to include:
- The NSIS installer executable.
- Electron update metadata (`latest.yml`).
- The matching blockmap file when generated by electron-builder.

Do not upload application source code, API credentials, OAuth client secrets, signing keys, or user data to this repository.

## Updating

Installed copies of BukoPie's Agents will use the public release feed configured into the application at build time. Only published, non-draft releases should be treated as stable updates.
